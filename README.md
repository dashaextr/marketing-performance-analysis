# Marketing Performance Analysis

## Overview
This project analyses marketing campaign performance to evaluate efficiency and identify optimisation opportunities.

## Key Questions
- What is the conversion rate of campaigns?
- How does cost per acquisition change?
- Which campaigns perform best?
- Where can performance be improved?

## Tools
- Excel
- Looker Studio

## Key Insights
- Identified opportunities to reduce cost per acquisition
- Analysed conversion trends across campaigns
- Highlighted areas of inefficient spend

## Business Recommendations
- Optimise underperforming campaigns
- Reallocate budget to high-performing channels
- Monitor conversion and cost metrics regularly
